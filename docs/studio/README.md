# Caffè Studio — planning documents

Caffè Studio is the terminal environment for supervising and working
alongside Caffè's agents. To use it, read the [user guide](user-guide.md).

The planning documents, in this order:

1. [audit.md](audit.md) — what the codebase does today and what Studio needs from it
2. [product-specification.md](product-specification.md) — vision, workflows, requirements, non-goals
3. [ux-specification.md](ux-specification.md) — layout, screens, navigation, agent visualization, states
4. [architecture.md](architecture.md) — packages, application API, events, state, terminals, editor, worktrees, LSP/DAP
5. [technical-decisions.md](technical-decisions.md) — ADRs with verified library facts
6. [roadmap.md](roadmap.md) — milestones, dependencies, acceptance criteria
7. [backlog.md](backlog.md) — independently reviewable tasks

Done items are marked `[x]` in [backlog.md](backlog.md).
